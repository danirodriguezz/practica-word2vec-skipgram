# Práctica 3 — Word2Vec (Skip-gram)

Práctica de Procesamiento del Lenguaje Natural: implementación de un modelo Word2Vec Skip-gram sobre un corpus pequeño.

## Contenido

- `practica_word2vec_skipgram.ipynb` — notebook con la implementación y el análisis.
- `dataset_word2vec.txt` — corpus (una frase por línea).
- `tabla_vecinos.csv` — vecinos más cercanos de palabras seleccionadas.
- `tabla_analogias.csv` — resultados de analogías.
- `Práctica_word2vec_skip-gram.pdf` — enunciado de la práctica.

## Uso

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook practica_word2vec_skipgram.ipynb
```
